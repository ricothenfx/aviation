# NX320 TSM · ATA 26 · Task 26-35-00-325-280 · engine fire detection loop element — fault isolation (warning message after power-up)
## Fault Code and Symptom

Fault code FC-2697-357 is reported for the engine fire detection loop element. Observed symptom: warning message after power-up.

This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Probable Causes

1. Faulty or contaminated lavatory smoke detector unit in the fire detection and extinguishing circuit.
2. Faulty or contaminated APU fire extinguishing bottle in the fire detection and extinguishing circuit.
3. Faulty or contaminated cargo compartment smoke detector in the fire detection and extinguishing circuit.
4. Open or chafed wiring between the engine fire detection loop element and its control unit.
