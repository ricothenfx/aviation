# NX320 TSM · ATA 49 · Task 49-19-00-463-410 · APU start contactor — fault isolation (intermittent indication)
## Fault Code and Symptom

Fault code FC-4935-666 is reported for the APU start contactor. Observed symptom: intermittent indication.

This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Probable Causes

1. Faulty or contaminated APU intake door actuator in the auxiliary power unit circuit.
2. Faulty or contaminated APU oil pressure transmitter in the auxiliary power unit circuit.
3. Faulty or contaminated APU start contactor in the auxiliary power unit circuit.
4. Open or chafed wiring between the APU start contactor and its control unit.
