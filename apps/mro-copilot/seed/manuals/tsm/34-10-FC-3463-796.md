# NX320 TSM · ATA 34 · Task 34-32-00-320-366 · standby attitude module — fault isolation (fails to respond to command)
## Fault Code and Symptom

Fault code FC-3463-796 is reported for the standby attitude module. Observed symptom: fails to respond to command.

This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Probable Causes

1. Faulty or contaminated magnetic variometer compensation module in the navigation and air data circuit.
2. Faulty or contaminated angle-of-attack sensor vane in the navigation and air data circuit.
3. Faulty or contaminated air data inertial reference unit in the navigation and air data circuit.
4. Open or chafed wiring between the standby attitude module and its control unit.
