# NX320 AMM · ATA 29 · 29-35-00 · Task 29-35-00-291-303 · case drain filter module — operational test
## General

This task card covers the operational test of the case drain filter module on the NX-320 hydraulic power generation and distribution (Hydraulic Power, ATA 29).
The case drain filter module is installed in the EDP drive shaft coupling and shares mounting hardware with adjacent systems.
Bench-test operating pressure reference for this card: 1302 bar.
This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Safety

The following hazards apply while working on the case drain filter module:

- Skydrol rapidly degrades eye tissue — goggles are mandatory
- the accumulator pre-charge side stays pressurized with the system depressurized

## Tools and Equipment

- NXT-777 system test set — calibrated within the last 12 months.
- NXT-210 torque wrench set — with the applicable adapter set.
- Seal kit NX-2976-310-A — Halcyon Hydraulics.

   NOTE: Verify the power transfer unit is relieved of stored energy before continuing.
