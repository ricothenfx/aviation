# NX320 AMM · ATA 34 · 34-37-00 · Task 34-37-00-266-126 · air data inertial reference unit — replacement
## General

This task card covers the replacement of the air data inertial reference unit on the NX-320 navigation and air data (Navigation, ATA 34).
The air data inertial reference unit is installed in the ADR pitot line disconnect panel and shares mounting hardware with adjacent systems.
This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Safety

The following hazards apply while working on the air data inertial reference unit:

- the standby battery keeps the attitude module live with all power off
- AOA vanes are mass-balanced — never rotate one backwards by hand

## Tools and Equipment

- NXT-845 pressure gauge rig — calibrated within the last 12 months.
- NXT-508 bonding meter — with the applicable adapter set.
- Seal kit NX-3469-627-A — Halcyon Hydraulics.

### Installation

1. Position the air data inertial reference unit on its mounts and hand-start all attach bolts before applying torque.
   NOTE: probe heat reaches burn temperatures within seconds when powered
2. Torque the air data inertial reference unit attach bolts to 35.9 lbf·ft in the crosswise sequence shown on the torque plate.
   CAUTION: Verify the air data inertial reference unit is relieved of power before continuing.
3. Reconnect the electrical connector of the air data inertial reference unit and confirm the latch clicks fully home.
   NOTE: the standby battery keeps the attitude module live with all power off

4. Restore the navigation and air data circuit supply to the air data inertial reference unit and bleed the applicable lines as specified.

### Test and Close-up

2. Record the reference value radio alt error 1.4 ft and compare it with the acceptance band for the air data inertial reference unit.
3. Cycle the air data inertial reference unit through 4 complete operating cycles and watch for hesitation or drift.
4. Leak-check every port and coupling touched during this task with the system at operating pressure.
