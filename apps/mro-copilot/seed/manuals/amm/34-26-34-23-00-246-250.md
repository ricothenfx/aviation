# NX320 AMM · ATA 34 · 34-23-00 · Task 34-23-00-246-250 · angle-of-attack sensor vane — operational test
## General

This task card covers the operational test of the angle-of-attack sensor vane on the NX-320 navigation and air data (Navigation, ATA 34).
The angle-of-attack sensor vane is installed in the AOA vane mounting mast and shares mounting hardware with adjacent systems.
Bench-test operating pressure reference for this card: 713 bar.
This card belongs to the simulated NX-320 training corpus (fictional aircraft; not for real-world maintenance use).

## Safety

The following hazards apply while working on the angle-of-attack sensor vane:

- the standby battery keeps the attitude module live with all power off
- AOA vanes are mass-balanced — never rotate one backwards by hand

## Tools and Equipment

- NXT-314 rigging pin kit — calibrated within the last 12 months.
- NXT-845 pressure gauge rig — with the applicable adapter set.
- Seal kit NX-3454-364-A — Meridian Gear Co..

### Installation

1. Position the angle-of-attack sensor vane on its mounts and hand-start all attach bolts before applying torque.
2. Torque the angle-of-attack sensor vane attach bolts to 30.0 lbf·ft in the crosswise sequence shown on the torque plate.
   NOTE: Verify the air data inertial reference unit is relieved of stored energy before continuing.
3. Reconnect the electrical connector of the angle-of-attack sensor vane and confirm the latch clicks fully home.
4. Restore the navigation and air data circuit supply to the angle-of-attack sensor vane and bleed the applicable lines as specified.
5. Apply gentle pressure and confirm the seal of the angle-of-attack sensor vane mating faces; replace the seal if extrusion is visible (seal kit NX-3454-364-A).

### Test and Close-up

1. Energize the navigation and air data test configuration and confirm the angle-of-attack sensor vane responds to command inputs.
2. Record the reference value vane friction torque 0.9 Nm and compare it with the acceptance band for the angle-of-attack sensor vane.
3. Cycle the angle-of-attack sensor vane through 5 complete operating cycles and watch for hesitation or drift.
4. Leak-check every port and coupling touched during this task with the system at operating pressure.
5. Monitor the radio altimeter height reads the bench reference at 30 ft during cycle 01 and log any deviation in the task sheet.
